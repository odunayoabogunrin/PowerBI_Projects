# RECRUITMENT ANALYTICS DASHBOARD

## Overview

This project showcases an interactive Recruitment Analysis Dashboard built in Microsoft Power BI to monitor and optimize hiring performance across business units, recruiters, departments, and recruitment channels.

The dashboard provides HR teams and leadership with actionable insights into:

- Hiring progress

- Recruitment pipeline efficiency

- Source effectiveness

- Position fulfillment timelines

- Candidate tracking

- Hiring KPIs

The solution is designed to support data-driven hiring decisions and improve recruitment operations.

## Business Problem

Recruitment teams often struggle with:

- Tracking hiring progress across multiple departments

- Measuring recruiter performance

- Identifying bottlenecks in hiring timelines

- Monitoring candidate pipeline stages

- Understanding which recruitment sources generate quality hires


This dashboard addresses these challenges by centralizing recruitment data into a single interactive reporting solution.

### Objectives

The main objectives of this project are to:

- Monitor recruitment KPIs in real time

- Analyze hiring trends and timelines

Track open vs completed positions

Evaluate recruiter and department performance

Identify effective candidate sourcing channels

Improve hiring completion rates

Enable faster HR decision-making
